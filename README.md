# SkillBridge
A responsive multi-page career and skill planner built with HTML, CSS and vanilla JavaScript only.

## Pages (10)
1. index.html — landing page
2. dashboard.html — overview and progress
3. careers.html — searchable career explorer
4. assessment.html — skill rating and readiness calculation
5. roadmap.html — editable completion checklist
6. tasks.html — personal task tracker
7. planner.html — weekly study planner
8. resources.html — searchable bookmarks
9. compare.html — career comparison
10. profile.html — profile, theme, export and reset settings

## Run
Open `index.html` in a modern browser. All state is saved locally in the browser with LocalStorage. No build step or backend is required.
The Google Fonts import is optional; the site uses fallback fonts if offline.
